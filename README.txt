طريقة التشغيل:
1) ثبّت Android Studio (آخر إصدار).
2) فك الضغط ثم File > Open > اختر مجلد MyKeyboard، وانتظر Gradle Sync (يحتاج إنترنت).
3) وصّل الهاتف (تصحيح USB) واضغط Run ▶  — أو Build > Build APK(s) وثبّت app-debug.apk.
4) افتح تطبيق "كيبوردي": فعّل الكيبورد ثم اختره.

المزايا الجديدة (شريط الأزرار أعلى الكيبورد):
⚙ ضبط  : شريط ارتفاع الكيبورد + شريط الفراغ بين الأزرار (تتغير مباشرة).
         زر "تعديل الأزرار": اضغط أي زر لتحديده ثم:
         ◀ ▶ ▲ ▼  تحريكه يميناً/يساراً/صف أعلى/صف أسفل
         ↔+ ↔−   عرض الزر      ↕+ ↕−   ارتفاع الزر
         "افتراضي" يعيد كل شيء كما كان. الإعدادات تُحفظ تلقائياً (لكل لغة تخطيط مستقل).
GIF    : يحتاج مفتاح GIPHY مجاني (لأن Tenor أُغلقت واجهته في 30/6/2026):
         developers.giphy.com > Create an App > API > انسخ المفتاح
         ثم الصقه في app/src/main/java/com/example/mykeyboard/Config.kt
         (قد يعطي GIPHY مفتاح تجريبي بحدود طلبات؛ للنشر العام اطلب مفتاح إنتاج).
ترجمة  : تترجم النص المحدد أو كل نص الحقل، ثم "استبدال" أو "إدراج".
         تستخدم نقطة Google Translate غير الرسمية (بدون مفتاح) وقد تتوقف أو تُحدّد الطلبات.
زخرفة  : اختر زخرفة فتُطبَّق على ما تكتبه مباشرة، أو اضغط "زخرف النص الحالي".
         الأطر (نجوم، زهور...) تُطبَّق على النص الموجود فقط.
         الزخرفة الإنجليزية تعمل على الحروف اللاتينية، والعربية (تطويل/تشكيل/مزخرف) على الحروف العربية.
         ملاحظة: بعض التطبيقات قد لا تعرض كل رموز الزخرفة.

======== البناء على GitHub بدون Android Studio ========
1) أنشئ مستودعاً جديداً على github.com.
2) ارفع كل محتويات المجلد (بما فيها المجلد المخفي .github).
3) تبويب Actions ← Build APK ← انتظر 3-6 دقائق حتى يصير أخضر ✅.
4) افتح عملية البناء ← قسم Artifacts ← نزّل MyKeyboard-apk ← فك الضغط ← ثبّت app-debug.apk.
(اختياري) مفتاح GIPHY: Settings ← Secrets and variables ← Actions ← New secret باسم GIPHY_KEY.
